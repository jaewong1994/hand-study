문제

두 집합 X={1,2,3,4}, Y={0,1,2,3,4,5}에 대하여 다음 조건을 만족시키는 함수 f:X→Y의 개수를 구하시오. [4점]

(가) x=1, 2, 3일 때, f(x)≤f(x+1)이다.

(나) f(a)=a인 X의 원소 a의 개수는 1이다.

(가) x=1, 2, 3일 때, f(x)≤f(x+1)이다.
(나) f(a)=a인 X의 원소 a의 개수는 1이다.
1
세는 것:f(1),f(2),f(3),f(4) 의 값
(가):f(1)≤f(2)≤f(3)≤f(4)
(나):f(a)=a 인 a 가 하나
a=1,2,3,4 일 때:(I)∼(IV)
나머지 x:f(x)=x

판단(나)는 f(a)=a인 a가 딱 하나라는 거니까, 그 a가 1, 2, 3, 4 중 무엇인지로 나누면 네 경우가 빠짐없고 서로 겹치지 않아.

주의그 a 말고 다른 x에서 f(x)=x가 되면 (나)를 어기니까, 나머지 자리는 모두 f(x)=x로 걸러야 해.

2
(I) f(1)=1: f(2)≥1, f(2)=2
f(2) 는 1, 3, 4, 5
f(2)=1: f(3) 는 1,2,4,5
f(3)=1: f(4) 는 1,2,3,5
f(3)=2: f(4) 는 2,3,5
f(3)=4 또는 5: f(4) 는 5

(가)로 앞 값보다 작아지지 않게, (나)로 f(2)=2, f(3)=3, f(4)=4만 빼면서 하나씩 내려가.

3
f(2)=1: 4+3+1+1=9
f(2)=3 또는 4: f(3) 는 4, 5
f(3)=4 또는 5: f(4) 는 5
f(2)=5: (f(3),f(4))=(5,5)
(I):9+2+2+1=14

f(2)=3이면 f(3)≥3인데 3은 (나) 때문에 빠져서 4, 5만 남아. f(4)도 4가 빠지니까 5 하나뿐이야.

4
(II) f(2)=2: f(1)≤2, f(1)=1
f(1) 는 0, 2
f(3)≥2, f(3)=3: f(3) 는 2,4,5
f(3)=2: f(4) 는 2,3,5
f(3)=4 또는 5: f(4) 는 5
(II):2×(3+1+1)=10

단축f(1)은 f(3), f(4)와 상관없이 정해지니까 앞쪽 2가지와 뒤쪽 5가지를 곱하면 돼.

5
(III) f(3)=3: f(4)≥3, f(4)=4
f(4) 는 3, 5
f(2)≤3, f(2)=2: f(2) 는 0,1,3
f(2)=0 또는 1: f(1) 는 0
f(2)=3: f(1) 는 0,2,3
(III):2×(1+1+3)=10

주의f(2)=1이면 f(1)≤1이지만 f(1)=1은 (나)를 어겨서 0 하나만 남아.

6
(IV) f(4)=4: f(3)≤4, f(3)=3
f(3) 는 0,1,2,4
f(3)=4: f(2) 는 0,1,3,4
f(2)=0 또는 1: f(1) 는 0
f(2)=3: f(1) 는 0,2,3
f(2)=4: f(1) 는 0,2,3,4

이번엔 뒤에서부터 f(3), f(2), f(1) 순서로 위쪽 한계를 내려가며 정해.

7
f(3)=4: 1+1+3+4=9
f(3)=1 또는 2: f(2) 는 0, 1
f(3)=0: f(2) 는 0
f(2)≤1: f(1) 는 0
(IV):9+2+2+1=14

f(3)=2여도 f(2)=2는 (나) 때문에 안 돼서 0, 1만 남아. f(2)≤1이면 f(1)은 1이 빠져 0뿐이야.

8
(I)∼(IV):14+10+10+14=48
예 f(1),f(2),f(3),f(4):0,2,4,5
(가):0≤2≤4≤5
(나):f(2)=2, f(1)=1
(나):f(3)=3, f(4)=4
경우(I)(II)(III)(IV)
