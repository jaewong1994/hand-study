문제

집합 X={−2,−1,0,1,2}에 대하여 다음 조건을 만족시키는 함수 f:X→X의 개수를 구하시오. [4점]

(가) X의 모든 원소 x에 대하여 x+f(x)inX이다.

(나) x=−2, −1, 0, 1일 때 f(x)≥f(x+1)이다.

(가) X의 모든 원소 x에 대하여 x+f(x)∈X이다.
(나) x=−2, −1, 0, 1일 때 f(x)≥f(x+1)이다.
1
(가):−2≤x+f(x)≤2
f(−2): 0, 1, 2
f(−1): −1, 0, 1, 2
f(0): −2, −1, 0, 1, 2
f(1): −2, −1, 0, 1
f(2): −2, −1, 0

x=−2이면 −2≤−2+f(−2)≤2라서 0≤f(−2)≤4야. f(−2)도 X의 원소니까 0, 1, 2만 남는 거지. 다른 x도 x+f(x)가 −2 이상 2 이하가 되게 범위를 잘라.

2
(나):f(−2)≥f(−1)≥f(0)≥f(1)≥f(2)
왼쪽:f(−2)≥f(−1)≥f(0)
오른쪽:f(0)≥f(1)≥f(2)
f(0)을 정하면 두 쪽은 따로
기준:f(0)=−2,−1,0,1,2

판단가운데 f(0)이 왼쪽 두 값과 오른쪽 두 값을 갈라 놓으니까 f(0)으로 경우를 나눠. 그러면 왼쪽 수와 오른쪽 수를 곱하면 돼.

f(0)의 값 다섯 가지는 빠짐없고 서로 겹치지 않아.

3
f(−1)=−1 또는 0⇒f(−2): 0, 1, 2
f(−1)=1⇒f(−2): 1, 2
f(−1)=2⇒f(−2): 2
왼쪽 수:f(−1)≥f(0)인 후보만 합

먼저 f(−1)마다 f(−2)가 몇 개인지 정리해 두면 f(0)이 바뀔 때 더하기만 하면 돼.

4
f(0)=−2: 왼쪽 3+3+2+1=9
f(0)=−1: 왼쪽 3+3+2+1=9
f(0)=0: 왼쪽 3+2+1=6
f(0)=1: 왼쪽 2+1=3
f(0)=2: 왼쪽 1

주의f(0)=−2여도 f(−1)은 −1부터라서 f(0)=−1일 때와 수가 같아. (가)로 자른 범위를 꼭 같이 봐야 해.

5
f(1)=0 또는 1⇒f(2): −2, −1, 0
f(1)=−1⇒f(2): −2, −1
f(1)=−2⇒f(2): −2
오른쪽 수:f(1)≤f(0)인 후보만 합

f(0)보다 오른쪽 값은 작거나 같아야 하니까 f(1)은 f(0) 이하, f(2)는 f(1) 이하인 것만 골라.

6
f(0)=2: 오른쪽 3+3+2+1=9
f(0)=1: 오른쪽 3+3+2+1=9
f(0)=0: 오른쪽 3+2+1=6
f(0)=−1: 오른쪽 2+1=3
f(0)=−2: 오른쪽 1

f(1)은 1까지만 되니까 f(0)=2와 f(0)=1의 수가 같아.
